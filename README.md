## 🛠 Daily Useful Tools

每天制作一个简洁实用的小作品，关注数字生活、效率与日常需求。优先本地处理、无需注册，让一个工具做好一件事。

### 第一个作品 / First tool

**[链接净化器 · Link Cleaner](https://zhongwilliam51-crypto.github.io/daily-useful-tools/link-cleaner.html)**

分享链接前，批量移除常见广告追踪参数，保留搜索内容、商品编号与视频时间点。零依赖，浏览器本地处理，可离线使用。

```text
https://example.com/article?id=42&utm_source=email
                         ↓
https://example.com/article?id=42
```

后续作品会持续加入[工具目录](https://github.com/zhongwilliam51-crypto/daily-useful-tools#工具目录--collection)。欢迎通过 [Issues](https://github.com/zhongwilliam51-crypto/daily-useful-tools/issues) 提出一个你想解决的生活小问题。
